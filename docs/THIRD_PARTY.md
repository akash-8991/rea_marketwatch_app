# Third-party material

MarketLens contains no third-party code at run time other than the items below. Nothing is downloaded when the app runs: icons and styles are files inside the
package. Build tools (Tailwind CLI, the Lucide package) are used only by `ui/` when the interface files are regenerated, and are not shipped.

| Item | Where | Licence | Use |
|---|---|---|---|
| **Lucide** icons (https://lucide.dev) | `src/marketlens/static/js/icons.js` (generated by `ui/gen-icons.mjs`, 58 icons as path data) | ISC; a few icons derive from Feather (MIT), both notices below | every interface icon |
| **Tailwind CSS** v4 (https://tailwindcss.com) | `src/marketlens/static/css/tailwind.css` (generated by `ui/`, utilities only, about 13 KB) | MIT | utility classes used by the newer components |
| **shadcn/ui** design system (https://ui.shadcn.com) | patterns, class API and token naming only; no source is copied | MIT | the component style (button, badge, alert, tabs, dialog, toast, command palette, skeleton) re-implemented as dependency-free ES modules in `static/js/ui.js` and `palette.js` |
| NSE Indices constituents list | `src/marketlens/data/ind_niftytotalmarket_list.csv` | published by NSE Indices; check NSE's terms before redistributing | stock names and industries |

## Why shadcn/ui is used as a design system and not as a package
shadcn/ui is a collection of React components on Radix UI primitives and Tailwind. MarketLens is a no-build static site served by a Python process, a container
and an Android WebView from one set of files, with nothing to compile at install time. Adding React would add a build step to every channel, a runtime of
roughly 45 KB (compressed) before any application code, and a rewrite of every screen and every test. The same visual and accessibility patterns are
therefore implemented directly on the web platform (native `<dialog>`, ARIA roles, CSS variables). If the project later moves to React, the tokens in
`style.css` and the component names in `ui.js` map one to one onto shadcn/ui.
